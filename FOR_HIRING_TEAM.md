# UI/UX Designer Take-Home Assignment Package

## For Hiring Managers & Interviewers

This package contains everything needed to evaluate UI/UX design candidates on their ability to leverage AI tools to rapidly prototype high-quality, interactive HTML designs.

---

## 📋 Package Contents

### For Candidates:

1. **README.md** - Main entry point with assignment overview and instructions
2. **task_instructions.md** - Step-by-step guide on how to approach the work
3. **evaluation_criteria.md** - Detailed rubric showing how they'll be assessed
4. **ai_prompting_guide.md** - Tips and strategies for effective AI usage
5. **design_guide.html** - Complete design system (colors, typography, components)
6. **product_requirements.md** - Full PRD for CineMatch movie discovery platform
7. **ui_screens.md** - Detailed specifications for each of the 5 screens
8. **QUICK_REFERENCE.md** - Handy cheat sheet for while they're working
9. **EXAMPLE_SUBMISSION_README.md** - Template showing what their submission should include

### For Hiring Team:

10. **FOR_HIRING_TEAM.md** (this file) - Guide for evaluators

---

## 🎯 What This Assignment Tests

### Primary Skills:

1. **AI Tool Proficiency** (20%)
   - Can they effectively leverage ChatGPT/Claude to accelerate work?
   - Do they customize AI outputs or just accept defaults?
   - Evidence of iterative refinement and strategic prompting

2. **Design System Adherence** (20%)
   - Do they follow the provided design guide?
   - Is styling consistent across all pages?
   - Proper use of CSS variables and design tokens

3. **Visual Design Quality** (20%)
   - Modern, professional aesthetic
   - Clear visual hierarchy
   - Attention to detail (spacing, alignment, typography)

4. **UX & Interactions** (20%)
   - Smooth animations and transitions
   - Intuitive navigation and user flows
   - Thoughtful micro-interactions

5. **Technical Implementation** (20%)
   - Clean, semantic HTML/CSS
   - Responsive design
   - No bugs or console errors
   - Working navigation between pages

### Secondary Assessment:

- **Time Management**: Can they deliver quality work in 3 hours?
- **Communication**: Is their README clear and insightful?
- **Problem Solving**: How did they handle challenges?
- **Design Judgment**: Do they make good decisions about priorities?

## 📊 Evaluation Process

### Step 1: Initial Review (5-10 minutes)

Check for completeness:
- [ ] All 5 HTML files present?
- [ ] README included with approach documented?
- [ ] Files properly organized and named?
- [ ] Did they exceed the 3-hour limit?

### Step 2: Visual Assessment (10-15 minutes)

Open each HTML file in browser:
- [ ] Matches design system aesthetics?
- [ ] Looks modern and polished?
- [ ] Consistent styling across pages?
- [ ] Smooth hover effects and transitions?
- [ ] Navigation works between pages?

### Step 3: Technical Review (10-15 minutes)

Inspect the code:
- [ ] Clean, semantic HTML?
- [ ] Proper use of CSS variables from design guide?
- [ ] Responsive design implemented?
- [ ] No console errors?
- [ ] Accessibility basics covered?

### Step 4: Detailed Scoring (15-20 minutes)

Use the rubric in `evaluation_criteria.md`:

| Criterion | Score (0-20) | Notes |
|-----------|--------------|-------|
| AI Leverage & Efficiency | /20 | |
| Design System Adherence | /20 | |
| Visual Design & Polish | /20 | |
| Interactions & UX | /20 | |
| Technical Implementation | /20 | |
| **Total** | **/100** | |

### Step 5: README Review (5 minutes)

Assess their documentation:
- Is their AI approach clearly explained?
- Do they show thoughtful customization?
- Are challenges and solutions documented?
- Professional tone and completeness?

## 🎯 Scoring Guidelines

### Excellent (90-100 points)

**What to expect:**
- All 5 pages completed and polished
- Perfect design system adherence
- Smooth, delightful interactions throughout
- Modern, professional visual design
- Clean code with no issues
- Clear evidence of sophisticated AI usage
- Insightful README documentation

**What it demonstrates:**
- Senior-level design sensibility
- Excellent time management
- Strategic AI tool usage
- Strong attention to detail
- Ready to contribute immediately

### Good (75-89 points)

**What to expect:**
- 4-5 pages completed
- Strong design system adherence
- Good interactions and polish
- Solid visual design
- Minor bugs or inconsistencies
- Evidence of AI usage
- Adequate README

**What it demonstrates:**
- Mid-level capabilities
- Can work with AI effectively
- Needs some refinement
- Trainable with mentorship

### Satisfactory (60-74 points)

**What to expect:**
- 3-4 pages present
- Moderate design consistency
- Basic interactions
- Acceptable visuals
- Some technical issues
- Basic AI usage
- Minimal documentation

**What it demonstrates:**
- Junior-level skills
- Basic understanding
- Needs significant training
- May struggle with autonomy

### Needs Improvement (<60 points)

**What to expect:**
- Fewer than 3 pages
- Poor design adherence
- Minimal interactions
- Unprofessional appearance
- Multiple technical issues
- Unclear AI usage

**What it demonstrates:**
- Not ready for the role
- Fundamental skill gaps
- Poor time management

## 🚩 Red Flags to Watch For

### Design Red Flags:
- ❌ Completely ignoring the design guide
- ❌ Using random colors/fonts
- ❌ Inconsistent styling across pages
- ❌ Poor visual hierarchy
- ❌ Cluttered layouts

### Technical Red Flags:
- ❌ Broken navigation links
- ❌ Console errors
- ❌ Non-responsive layouts
- ❌ Copy-pasted generic templates without customization
- ❌ No evidence of testing

### Process Red Flags:
- ❌ Clearly spent way more than 3 hours (over-engineered)
- ❌ No README or minimal documentation
- ❌ Couldn't articulate AI usage strategy
- ❌ Made excuses instead of documenting challenges

### AI Usage Red Flags:
- ❌ Generic AI outputs with no customization
- ❌ No evidence of AI usage at all (manually coded everything)
- ❌ Can't explain how they used AI
- ❌ AI usage was inefficient (wasted time)

## 💬 Interview Discussion Topics

Use their submission as a springboard for deeper conversation:

### Questions About Their Approach:

1. "Walk me through your process. How did you decide what to build first?"
2. "How did you use AI in this assignment? What was your prompting strategy?"
3. "What was the most challenging part, and how did you solve it?"
4. "If you had another 3 hours, what would you improve?"
5. "How did you ensure consistency across all 5 pages?"

### Questions About Design Decisions:

1. "Why did you choose these specific hover effects?"
2. "How did you approach the responsive design?"
3. "What influenced your layout decisions for [specific page]?"
4. "Were there any parts where you deviated from the design guide? Why?"

### Questions About AI Usage:

1. "What's your general workflow when using AI for design work?"
2. "How do you decide what to ask AI vs. what to code yourself?"
3. "Have you used AI in real projects before? How?"
4. "What are the limitations of AI for design work?"

### Questions About Trade-offs:

1. "How did you prioritize with limited time?"
2. "What features did you cut or simplify? Why?"
3. "If you could only polish one page, which would it be and why?"

## 📞 Support for Candidates

### If Candidates Ask Questions:

**Clarifying questions**: Answer promptly
- Example: "Should navigation be sticky?" → "Your choice, document reasoning"

**Design decisions**: Don't answer
- Example: "What color should this button be?" → "Refer to design guide"

**Technical issues**: Help with setup only
- Example: "Browser won't open HTML" → Help troubleshoot
- Example: "How do I make this animation?" → Don't answer

### Sample Response Template:

```
Hi [Candidate],

Great question about [topic]. 

[If clarifying]: Here's the clarification: [answer]

[If design decision]: This is a design decision we'd like you to make 
based on the design guide and your judgment. Document your reasoning 
in your README!

[If technical]: Please refer to [specific document] which covers this.

Feel free to reach out if you have other clarifying questions!

Best,
[Your Name]
```
