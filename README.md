# UI/UX Designer Take-Home Assignment

## Welcome! 👋

Thank you for your interest in joining our team. This assignment is designed to evaluate your ability to leverage AI tools (like Cursor, Claude, or similar) to rapidly prototype high-quality, interactive UI designs.

## ⏱️ Time Limit: 3 Hours Maximum

This is a timed assignment. We want to see how efficiently you can work with AI to produce polished results, not test your ability to manually code for days. **Please do not spend more than 3 hours on this task.**

## 📋 What You'll Be Building

You'll be creating clickable HTML prototypes for **CineMatch** - a movie discovery platform that helps users find their next favorite film. This is a simplified product with **5 core screens** and no authentication required.

## 📁 Assignment Structure

This folder contains everything you need:

- `design_guide.html` - Complete design system with colors, typography, components
- `product_requirements.md` - PRD detailing the product vision and features
- `ui_screens.md` - Detailed specifications for each screen you'll build
- `task_instructions.md` - Step-by-step guide on how to approach this
- `evaluation_criteria.md` - How your work will be assessed
- `ai_prompting_guide.md` - Tips for effectively using AI to build prototypes

## 🎯 Your Deliverables

Submit the following in a folder named `[YourName]_cinematch_prototype`:

1. **5 HTML files** (one for each screen):
   - `landing.html` - Homepage with featured movies
   - `browse.html` - Movie catalog with filters
   - `movie_details.html` - Individual movie page
   - `watchlist.html` - Saved movies collection
   - `search_results.html` - Search results page

2. **A brief README** (5-10 minutes to write) that includes:
   - Your overall approach/strategy
   - What you'd improve with more time
   - Any challenges you encountered

## 🚀 Getting Started

1. **Read all documentation files** (15-20 minutes)
2. **Review the design guide** carefully - this is your design system (however bonus points for being able to leverage Cursor to tweak/personalize the design system)
3. **Follow the task instructions** in `task_instructions.md`
4. **Use AI strategically** - see `ai_prompting_guide.md` for tips
5. **Focus on quality over quantity** - better to have 3 polished screens than 5 mediocre ones

## ⚡ Quick Tips

- Open `design_guide.html` in your browser as a reference while working
- Use the provided CSS variables and components from the design guide
- Make sure your pages are clickable/navigable (links between pages should work)
- Test in a modern browser (Chrome, Firefox, Safari, or Edge)
- Include smooth transitions and micro-interactions where appropriate
